# Keychron notes (Q6 Ultra and similar)

On Linux, set the physical **Mac / Windows** switch to **Windows**.

- **Mac** position activates Layer 0 (Cmd/Option placement feels wrong in GNOME)
- **Windows** position activates Layer 2 (Win key = Super)

Remap top-right keys in [Keychron Launcher](https://launcher.keychron.com) (wired + Chrome), editing **Layer 2**.

Suggested consumer keys: Calculator, WWW, Explorer, Mail, Search — bind Search to the launcher via GNOME custom shortcuts if desired.
